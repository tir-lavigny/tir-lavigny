# Agents

Web app for Tir Lavigny.

## Technologies

- PHP
- Laravel
- MariaDB (Production)
- SQLite (Development)
- TypeScript
- Vue.js
- Inertia.js (bridge between Laravel and Vue.js)
- Shadcn UI (and Tailwind CSS for layout)

### Tests

- PHPUnit
- Vitest
